# Working notes

- Backend: `backend/src/support_workspace/`; Next.js/CopilotKit v2: `frontend/`. `api.py` exposes cases, explicit decisions, evidence and native `/agent` AG-UI. The model has read/proposal tools only. Approval is a separate operator REST call.
- `runtime.py` constructs/owns sync+async SDK/HTTP clients and MemorySaver in ASGI lifespan. `build_agent` takes caller-owned dependencies and closes neither. Use `with TestClient(...)`; starting another lifespan must use fresh clients/routes/checkpoints. Close responses on failure/cancellation; clear volatile checkpoints only on shutdown, preserving durable evidence/business state.
- `evidence.py` wraps real JSON/SSE transports. Preserve raw usage before SDK defaults, include thread/run IDs and state/input hashes, never infer cost/zeros. Keep a single stream iterator when the SDK drains HTTP/1.1. Capture/decode/truncation problems remain explicit; no `[DONE]` or nonfinal output cannot dispatch tools. `completion.py` applies matching sync/async guards and removes rejected orphan calls on later turns while retaining evidence.
- Eight model calls/run, 30-second HTTP timeouts, 4,096 output tokens, no automatic retries/redirects/model cache/storage. Only the normal actual provider path exists in source; test HTTP is explicitly injected in tests. Do not turn controlled responses into live-model quality or billing claims.
- State: one JSON file. One backend process/worker and one operator per path. ASGI chat runs serialize; REST mutations use a shared lock/revision. Serialize direct runtime calls too. Atomic file publication is not a cross-process or remote payment transaction. Disconnecting an observer does not prove provider generation/billing stopped.
- Proposals bind exact order/customer/currency; approval rechecks scope, status, identity, revision and remaining balance. Preserve exact integer cents/revisions and noncontiguous refund IDs. Unknown legacy binding needs a fresh proposal before approval; rejection remains available. Exact proposal retries preserve revision. A later model error does not roll back a saved proposal.
- UI reads committed state. Keep decision/chat failures visible, abort stale record reads and gate chat on agent discovery. Operator decisions carry the displayed revision. The API is unauthenticated and loopback-only for this demo; do not expose it publicly.
- Dataset `northstar-support-workspace` 1.0.0: eight cases/four profiles, busy state with 18 cases/orders and prior refunds/proposals/rejection. `scripts/build_fixtures.py` reproduces every byte. Model-free help/list/init must work without keys; initialization is private/exclusive, reset local JSON only. Seeded history is fictional business state, with no invented SDK/provider observations. Dataset/criteria/manifest labels never enter model tools.
